# 一、项目概述

## 1.1 项目背景

当前小学英语在低年级和中年级阶段常采用**自然拼读（Phonics）**教学，但到高年级后，学校可能会开始补充**音标（IPA）**内容。现实问题是：

- 音标在学校中往往不是完整教学主线；
- 老师讲解可能偏零散，不成体系；
- 孩子对“自然拼读”和“音标”的关系容易混淆；
- 市面上很多产品要么太低幼，要么太像练习册；
- 很多产品偏“背音标”，缺少和教材词汇的直接结合；
- 家长希望孩子能真正建立：
  - 看单词会尝试读；
  - 看音标能辅助纠音；
  - 听发音能自我校正。

因此，本项目希望打造一个：

> **面向小学生、以教材词汇为入口、以自然拼读为基础、以音标为辅助、兼顾逐音发音训练的原创英语学习小程序。**

---

## 1.2 产品目标

### 核心目标
帮助孩子建立以下能力链路：

> **课本单词 → 自然拼读尝试 → 识别声音 → 理解音标 → 听标准发音 → 正确朗读**

### 产品目标
1. 提供一张类似 Cambridge 风格的**音标总表**；
2. 提供**逐音（音标）发音**能力；
3. 提供**整词发音 + 逐音拆解发音**能力；
4. 将**PEP 六年级词汇**与自然拼读、音标关联起来；
5. 产品框架支持后续扩展到：
   - 其他年级
   - 其他学期
   - 其他教材版本
   - 用户自定义词汇收藏与学习
6. 整体视觉要**吸引孩子**，但避开版权问题，不使用任何知名 IP 角色。

---

## 1.3 产品定位

### 产品类型
儿童英语发音学习工具型小程序

### 产品定位一句话
> 一个以教材词汇为入口、融合自然拼读与音标体系、支持逐音发音训练的原创英语学习小程序。

# 三、产品原则

## 3.1 教学原则

### 原则 1：单词优先，音标辅助
不是直接教“48 个音标”，而是通过**课本单词**带出音素和音标。

### 原则 2：自然拼读与音标打通
自然拼读解决“可能怎么读”，音标解决“准确怎么读”。

### 原则 3：以英式英语为主
默认采用标准英式发音体系，后续可扩展美式。

### 原则 4：优先训练听、认、读
不要求孩子默写音标，重点是：
- 听得出
- 认得出
- 读得出

### 原则 5：轻学习、轻游戏化
不做重度游戏，不做复杂闯关和社交，强调：
- 易打开
- 易坚持
- 易复习

---

## 3.2 产品原则

1. **通用框架优先**：PEP 六年级只是第一套内容；
2. **内容结构化优先**：底层数据要能复用；
3. **可扩展优先**：教材、词库、练习、发音模块都可增量扩展；
4. **原创视觉优先**：不使用任何 IP 人物；
5. **儿童友好但不低幼**：适配 10～12 岁审美；
6. **开发务实**：第一版尽量轻量、可快速上线验证。

# 五、核心功能设计

---

## 5.1 功能一：音标总表

### 目标
提供一张类似 Cambridge 风格的音标总表，成为产品的“声音地图”。

### 功能要点
- 按音类分区展示：
  - 短元音
  - 长元音
  - 双元音
  - 辅音
- 每个音标卡片展示：
  - 音标符号
  - 示例词
  - 常见拼写
  - 播放按钮
- 点击音标可：
  - 播放单独音素
  - 进入音标详情页

### 每个音标详情页包含
- 音标本身
- 单独发音
- 发音说明
- 常见拼写
- 示例词
- 相似音对比
- 已学课本词关联
- 相关训练入口

---

## 5.2 功能二：逐音发音

这是产品的核心亮点之一。

### 支持三种播放模式

#### 模式 1：单独音素播放
例如 `/aɪ/`，点一下只播放这个音。

#### 模式 2：逐音拆解播放
例如 `climb /klaɪm/`，依次播放：
- /k/
- /l/
- /aɪ/
- /m/

#### 模式 3：完整单词播放
例如直接播放 `climb`

---

## 5.3 功能三：跟课本学

### 目标
以教材内容作为学习入口，让孩子在熟悉场景中学习音标和拼读。

### 学习路径
教材 → 年级 → 学期 → Unit → 单词

### 单词详情页内容
- 单词
- 中文
- 整词发音
- 音标
- 音节划分
- 逐音拆解
- 自然拼读拆解
- 核心音素
- 同音词/近音词
- 小练习
- 收藏到我的单词

---

## 5.4 功能四：拼读训练

### MVP 题型建议

#### 题型 1：听音选词
播放一个单词或单个音，选择正确词。

#### 题型 2：看词选音标
例如：
- clay
- 选正确音标

#### 题型 3：听词选核心音
例如：
- 播放 climb
- 选它的核心元音是 `/aɪ/`

#### 题型 4：同音归类
下面哪个词与 `day` 的元音相同？

#### 题型 5：相似音辨析
例如：
- sheep / ship
- bed / bad
- food / good

---

## 5.5 功能五：我的单词

### 目标
让用户可以在学习过程中持续积累自己的词库。

### 功能点
- 收藏教材词
- 手动输入新单词
- 创建自定义词单
- 自动进入复习系统
- 支持后续再次学习

### 词单类型建议
- 我的收藏
- 最近生词
- 容易读错
- 自定义词单

---

## 5.6 功能六：今日学习

### 目标
降低决策成本，打开即可学。

### 今日学习内容
- 今日新词 2～3 个
- 今日重点音 1～2 个
- 今日训练 5 题
- 今日复习若干

### 生成逻辑
来自：
- 当前教材进度
- 最近错误音素
- 最近收藏词汇
- 已学词中的薄弱项

# 九、内容与数据设计

---

## 9.1 产品底层核心模型

这个产品真正的底层不是“教材”，而是：

> **Phoneme（音素） ↔ Grapheme（字母/字母组合） ↔ Word（单词）**

教材只是单词的组织方式之一。

---

## 9.2 核心实体

### 1）Phoneme 音素

```json
{
  "id": "ipa_ai",
  "symbol": "/aɪ/",
  "category": "vowel",
  "subCategory": "diphthong",
  "audio": "phonemes/ai.mp3",
  "exampleWord": "bike",
  "commonSpellings": ["i_e", "igh", "y", "i"],
  "contrast": ["ipa_ei", "ipa_i_short"]
}
```

---

### 2）Word 单词

```json
{
  "id": "word_climb",
  "word": "climb",
  "meaning": "攀登；爬",
  "ipa": "/klaɪm/",
  "accent": "en-GB",
  "syllables": ["climb"],
  "phonemes": ["ipa_k", "ipa_l", "ipa_ai", "ipa_m"],
  "segments": [
    {
      "grapheme": "cl",

      "grapheme": "i",
```

## 9.3 数据层原则

1. 同一个单词只存一份；
2. 教材只是组织关系，不与单词强绑定；
3. 音标总表、教材学习、我的单词共享同一底层数据；
4. 未来新增教材只需新增 curriculum 数据；
5. 自定义单词也进入同一套学习系统。

# 十、音频设计方案

---

## 10.1 音频类型

### A. 音素音频
- 对应 `/iː/ /ɪ/ /æ/ /θ/` 等基础音
- 数量少，建议固定资源化
- 质量要求高

### B. 单词音频
- 对应具体单词
- 可采用预置 + 后续扩展方案

### C. 逐音拼读音频
有两种实现思路：

#### 方案 1：预制拼接
单词详情页按音素顺序播放多个音素音频，再补整词音频

#### 方案 2：后续更高级实现
做更自然的“逐步融合式拼读播放”

MVP 建议先做方案 1。

---

## 10.2 推荐 MVP 音频策略

第一版建议：

- **44 个基础音素音频**：固定资源
- **PEP 六年级核心单词音频**：固定资源或可配置资源
- **逐音发音**：用音素音频串联播放
- **整词发音**：独立整词音频

这样最稳。
