## 本轮开发后的实际可用性

收藏、自定义词、教材浏览、今日计数、翻卡复习已经实现。根据用户纠偏，145个教材词的详情/列表/复习卡显示待核对 IPA。整词渐变来自真实媒体currentTime/duration，停止、切词及结束归零。浏览器使用用户授权的系统英式整词试听，正式小程序仍无可播放录音。三类练习继续只使用已审核数据，因此当前为空态。

`npm run content:status` 输出内容计数，`node scripts/content-status.cjs --release` 会明确拒绝将当前内容认定为发布就绪。`learning-samples.json` 和 `audio-candidates.json` 不进入运行时打包；来源证据、结构通过和发音审核分别记录。
