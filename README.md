# 拼读星球 · Phonics Planet

面向小学高年级的英语发音学习微信小程序。当前是**十一开发准备包 + 可导入的原生小程序骨架**，不是已完成的学习产品。

## 启动

1. 安装 Node.js 20 或更新版本，无需 npm install。
2. 执行 `npm run check` 校验数据、生成运行时数据并运行服务测试。
3. 微信开发者工具导入仓库根目录；项目配置已指向 `miniprogram/`。
4. `touristappid` 是占位值，请在开发者工具使用自己的测试 AppID；个人配置不要提交。
5. 编译后从首页进入音标总表、教材 → 单元 → 单词、我的单词。

## 给后续 AI 的入口

先读 `AGENTS.md`，再读 `PRODUCT.md`、`DESIGN.md`、`DATA.md`、`IMPLEMENTATION.md` 和 `docs/CONTENT-STATUS.md`。自行规划后续开发，不预设细分任务清单。

## 已准备

- 原生小程序 7 个页面：静态首页、44 音素总表、音素详情、教材、单元、单词详情、收藏列表。
- 44 个传统英式音素：20 元音、24 辅音；常见拼写、例词、易混关系。
- 新版 PEP 六上 6 单元、146 条教材关联、145 个 Word；单元语境释义独立。
- AudioService、StorageService、ContentService；取消播放、缺失音频降级、收藏本地持久化。
- 原创首页插画、SVG 图标源文件、主题色、页面线框、资源来源记录。
- 数据构建、引用与完整性校验、关键服务测试。

## 内容状态

教材数据是根据公开词表重新整理的待审核种子数据；并非取回原 ChatGPT 压缩包。未混入旧版六下。IPA、音节与字母对齐尚未补全，例词发音教学说明尚待审核。当前没有正式发音音频，按钮会说明正在准备，绝不以静音文件假冒发音。音频清单记录 189 个资源位，后续填入授权来源并审核。

练习、今日学习、复习算法、自定义词输入留给后续 AI 规划；本次没有假造学习进度。微信开发者工具编译与真机验收尚需执行。

## 目录

- `seed-data/`：唯一可编辑的内容数据；`examples/` 是隔离示例。
- `miniprogram/`：应用、页面、服务；`data/generated.js` 由构建脚本生成。
- `assets/`：设计源素材和来源清单；运行时图片在小程序 assets 下。
- `scripts/`、`tests/`：无第三方依赖的数据构建和校验。
- `docs/`：审核状态、来源、音频规范、原对话设计参考。

不包含 AppID 密钥、后端、账号体系或云同步。没有自动 commit 或 push。
