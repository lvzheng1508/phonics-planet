# 拼读星球 · Phonics Planet

面向小学高年级的英语发音学习微信小程序。当前已实现本地学习流程，可浏览教材、收集单词、添加自定义词并翻卡复习。**发音内容尚未审核完成，暂不是可发布的发音教学版本。**

## 启动

1. 安装 Node.js 20 或更新版本，执行 `npm ci`。
2. 执行 `npm run check` 校验数据、生成运行时数据、运行行为测试及 WXML/WXSS 编译检查。
3. 微信开发者工具导入仓库根目录；项目配置已指向 `miniprogram/`。
4. `touristappid` 是占位值，请在开发者工具使用自己的测试 AppID；个人配置不要提交。
5. 编译后可操作首页、教材、44 音素总表、单词详情、我的单词、今日学习、翻卡复习及练习入口。

浏览器快速预览：`npm run preview`，打开 http://127.0.0.1:4173 。预览复用真实页面控制器与编译后的 WXML，数据保存在浏览器本地；它不能替代微信开发者工具或真机验收。仅开发工具依赖 npm 包，小程序没有运行时第三方依赖。

## 给后续 AI 的入口

先读 `AGENTS.md`，再读 `PRODUCT.md`、`DESIGN.md`、`DATA.md`、`IMPLEMENTATION.md`、`docs/CONTENT-STATUS.md` 与 `docs/HANDOFF.md`。自行规划后续开发。

## 已准备

- 原生小程序 11 个页面：首页、44 音素总表、音素详情、教材、单元、单词详情、我的单词、今日学习、复习、练习、来源说明。
- 44 个传统英式音素：20 元音、24 辅音；常见拼写、例词、易混关系。
- 新版 PEP 六上 6 单元、146 条教材关联、145 个 Word；单元语境释义独立。
- AudioService 统一整词与逐音播放机制、取消、状态与片段高亮；缺失或未审核资源禁用。
- 收藏与自定义词共用 Word 模型；今日真实计数、最近浏览、基于所选单元的学习入口。
- 翻卡后自评，按 1/3/7/14 天安排复习；重复点击不重复计数，读写失败不覆盖已有记录或推进评分。
- 听音选词、看词选音标、寻找同类音的出题与评分流程，只使用满足条件的已审核内容。
- 原创首页插画、SVG 图标源文件、主题色、页面线框、资源来源记录。
- 数据构建、引用与完整性校验、关键服务测试。

## 内容状态

教材数据是根据公开词表重新整理的待审核种子数据；并非取回原 ChatGPT 压缩包。未混入旧版六下。IPA、音节与字母对齐尚未补全，例词发音教学说明尚待审核。当前没有正式发音音频，按钮会说明正在准备，绝不以静音文件假冒发音。音频清单记录 189 个资源位，后续填入授权来源并审核。

`seed-data/learning-samples.json` 保存 6 个带 IPA 来源的拼读候选，AI 对齐仍待审核，未导入运行时。`seed-data/audio-candidates.json` 保存 12 个候选的逐项证据；部分已找到许可及口音说明，但下载连接被重置，没有下载试听或假定审核完成。

三类练习当前均显示空态，因为真实词库没有已审核发音内容。`npm run content:status` 查看实际缺口；`node scripts/content-status.cjs --release` 在未就绪时故意返回失败。代码检查通过不代表内容审核或真机音频验收通过。微信开发者工具编译与真机验收尚需执行。

## 目录

- `seed-data/`：唯一可编辑的内容数据；`examples/` 是隔离示例。
- `miniprogram/`：应用、页面、服务；`data/generated.js` 由构建脚本生成。
- `assets/`：设计源素材和来源清单；运行时图片在小程序 assets 下。
- `scripts/`、`tests/`：数据构建、行为测试、模板编译与浏览器预览。
- `docs/`：审核状态、来源、音频规范、原对话设计参考。

不包含 AppID 密钥、后端、账号体系或云同步，不采集儿童身份数据。不擅自 push。
